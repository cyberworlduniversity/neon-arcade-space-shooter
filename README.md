# Neon Arcade Space Shooter

A browser-based 3D neon arcade space shooter built with Three.js, HTML, CSS, and JavaScript.

## Play

Open `index.html` in a modern WebGL-capable browser, or use the deployed Vercel demo.

## Features

- 3D neon space environment
- Keyboard and touch controls
- Shooting and collision detection
- Multiple enemy types
- Waves and progressive difficulty
- Health, score, high score, and power-ups
- Particle explosions and impact effects
- Pause, restart, and game-over states
- Local high-score persistence
- No backend or API key required

## Controls

- **WASD / Arrow keys:** Move
- **Space:** Fire
- **P:** Pause
- **Touch:** Use the on-screen controls on mobile

## Technology

Three.js, HTML5, CSS3, JavaScript.
